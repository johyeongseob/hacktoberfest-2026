# Use GitHub Copilot to Build a Simple Application

**Repository:** [johyeongseob/copilot-adventure-game](https://github.com/johyeongseob/copilot-adventure-game)

## What I built

**The Lantern at Blackwater Marsh**, a command-line choose-your-own-adventure game in Python: one file (`adventure.py`), three main branches, six endings, and input validation that asks again on invalid choices.

## How

1. Created a new public repository with a README and opened a codespace.
2. Sent one prompt to Copilot in Agent mode:

   > Build a command-line "choose your own adventure" game in Python. Use a single file adventure.py with at least 3 branching choices and multiple endings. Update README.md with a short description and how to run it. Do not create a virtual environment or run tests.

3. Copilot generated `adventure.py` and updated `README.md` in about 50 seconds.
4. Played it through to an ending, then committed and pushed.

## Run it

```bash
python adventure.py
```
